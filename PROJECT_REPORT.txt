1. Introduction
The Shopping List Manager is a simple Python program that helps a user organize items they plan to buy. The program runs in the command line and displays a menu of actions.
A user can add an item, view the shopping list, update an item's quantity, mark an item as purchased, remove an item, search for an item, and calculate the estimated cost.
The program stores items in a Python list while it is running. The list is not saved after the program closes.

2. Objectives
The objectives of this project are:
- To practise basic Python programming.
- To use lists and dictionaries to store information.
- To use functions to organize a program.
- To use loops and conditions to control program flow.
- To accept and process user input.
- To calculate the total cost of shopping items.

3. Problem Description
Keeping track of items to buy can be difficult, especially when there are several items with different quantities and prices. This program provides a basic way to manage a shopping list.
Each item has a name, quantity, price, and purchase status. The program uses these details to display the list and calculate the total cost.

4. Scope
The program is designed for simple, personal use in a terminal. It can manage one shopping list during a single program run.
The program does not use a database or save items to a file. When the program is closed, the items entered during that run are lost.

5. Features
- Add item: Adds an item with a name, quantity, and price.
- View list: Displays all items and their purchase status.
- Update quantity: Changes the quantity of a selected item.
- Mark as purchased: Changes the selected item’s status to purchased.
- Remove item: Deletes an item from the list.
- Search: Finds items whose names contain the search word.
- Calculate total: Displays the total value, purchased value, and pending value.
- Input checks: Displays a message when a number input is invalid.

8. Data Structure
Each shopping item is stored as a dictionary. For example:
item = {
    "name": "Milk",
    "quantity": 2,
    "price": 40.0,
    "purchased": False
}
The dictionaries are stored together in a list:
items = []
This allows the program to manage multiple items using one list.

9. Program Logic
The program first creates an empty list for the shopping items. It then displays a menu inside a loop.
The user enters a menu option. The program checks the choice and calls the relevant code to perform that action. The menu appears again after the action finishes. The loop ends when the user selects the exit option.
The total cost for each item is calculated as:
item cost = quantity × price
The program adds each item cost to the total. It also adds the cost to the purchased total if the item has been marked as purchased. The pending total is calculated by subtracting the purchased total from the overall total.

10. How to Run the Program
1. Save the Python code in a file named shopping_list.py.
2. Open a terminal or command prompt in the folder containing the file.
3. Run the program using:
python shopping_list.py
On Windows, this command can also be used:
py shopping_list.py

12. Limitations
- Items are stored only while the program is running.
- The list is lost when the program closes.
- The program does not use a database or file for storage.
- Prices and quantities must be entered by the user.
- The program does not check whether the price or quantity is positive.

13. Future Improvements
The program could be improved by:
- Saving and loading the shopping list from a file.
- Checking that quantities and prices are positive.
- Adding categories for items.
- Adding a budget limit.
- Supporting multiple shopping lists.
- Creating a graphical user interface.

14. Conclusion
The Shopping List Manager provides a simple way to organize items and estimate their cost. Developing it gives practice with Python lists, dictionaries, functions, loops, conditions, user input, and basic exception handling. Because the program stores data only during the current run, a future version could add file storage to keep the list between sessions.
