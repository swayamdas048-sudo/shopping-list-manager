1. Project Overview
The Shopping List Manager is a Python program that helps users manage a shopping list through a text-based menu.
Users can add items, view the list, update quantities, mark items as purchased, remove items, search for items, and calculate the estimated cost.
The items are stored in a Python list while the program is running. They are not saved after the program closes.

3. Features
Shopping List
- Add an item with its name, quantity, and price.
- View all items and their purchase status.
- Update an item's quantity.
- Mark an item as purchased.
- Remove an item from the list.
- Search for an item by name.
  
Cost Calculation
- Calculate the total cost of all items.
- Show the value of purchased items.
- Show the value of items still to be purchased.

8. Running the Program
Open a terminal in the project folder and run:
python shopping_list.py
On Windows, you can also run:
py shopping_list.py
The program displays a menu with options for managing the shopping list. Enter the number for the action you want to perform.

10. Example
A user can add an item with these details:
Item: Milk
Quantity: 2
Price: 40
The cost of that item is 2 × 40 = 80.
The item can then be marked as purchased, updated, searched for, or removed.

12. Limitations
- Items are kept only while the program is running.
- The list becomes empty when the program is closed.
- Prices must be entered by the user.
- The program does not connect to an online product database.
