# Project Statement: Shopping List Manager

## Problem Statement

People may forget planned purchases or have difficulty estimating the cost of a shopping trip. This project provides a simple command-line program for organizing items, quantities, prices, and purchase status in one list.

## Scope

The program manages one shopping list during a single run. It supports adding, viewing, updating, searching, marking, and removing items, and calculating total, purchased, and pending values. Items are held in memory and are cleared when the program exits. File storage, databases, online products, and user accounts are outside the current scope.

## Target Users

Students or individuals who need a basic personal shopping checklist and want to practise introductory Python programming concepts.

## High-level Features

- Add an item with a name, quantity, and price.
- View items and purchase status.
- Update an item's quantity.
- Mark an item as purchased.
- Remove an item.
- Search item names.
- Calculate total, purchased, and pending costs.
- Handle common invalid numeric and item-number input.
